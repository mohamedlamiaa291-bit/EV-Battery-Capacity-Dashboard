# 📊 EV Battery Capacity & Performance Intelligence

An end-to-end Data Analytics project designed to analyze battery capacity metrics, performance efficiency, and technical specifications across **478 Electric Vehicle (EV) models**. This project demonstrates complete proficiency in ETL processes, data modeling, custom theme engineering, and visualization using **Power BI** and **Power Query**.

---

## 🎯 Business Goal & Project Context

The global transition toward electric mobility requires data-driven analysis of battery efficiency and vehicle specs. This project analyzes a comprehensive dataset of **478 EV models** to uncover key insights into battery capacity distributions (usable kWh), range correlations, and technical specifications to guide executive decision-making.

## ❓ Business & Research Questions

To achieve the project objectives, this analysis addresses the following core questions:

1. **Capacity Distribution:** How is usable battery capacity distributed across different EV manufacturers and market segments?
2. **Efficiency Trends:** What is the relationship between battery capacity (kWh), vehicle weight, and driving range?
3. **Market Segmentation:** Which battery capacity tiers represent the majority of available EV models?
4. **Design Integration:** How can a custom dark UI theme enhance executive dashboard readability and metric scanning?

---

## 🔍 Key Insights & Analysis Results

- Analyzed technical metrics across **478 distinct EV models**, categorizing them by usable battery capacity tiers.
- Built calculated measures and attributes using **Power Query** and **DAX** to evaluate performance trends.
- Standardized visual layout using a custom dark theme design to optimize executive reporting clarity.
- Complete documentation generated in both **Arabic and English** to support technical and non-technical stakeholders.

## 🔄 Analytics Workflow

---

## ⚙️ Methodology & Analytics Steps

1. **Business Goal Definition:** Identifying key battery metrics, capacity KPIs, and visual specifications required for executive reporting.
2. **Data Cleaning & Transformation (ETL):** Handling null values, standardizing capacity units (kWh), and filtering raw records in Power Query.
3. **Data Modeling & DAX Calculation:** Building explicit DAX measures, calculated columns, and data relationships.
4. **UI/UX Custom Theme Engineering:** Designing and applying a custom JSON theme (`Black_Gold_Theme.json`) for dark-mode visualization.
5. **Insight Extraction & Documentation:** Documenting executive findings and compiling comprehensive Bilingual User Guides.
